# Roadmap

This is a directional roadmap, not a delivery commitment.

## v0.1.0 — public prototype

- [x] Personal account registry and lifecycle labels
- [x] Preferred legacy instructions
- [x] Trusted-contact records (local-only, no invitations)
- [x] JSON export and print summary
- [x] Fictional professional-workflow preview
- [x] Prototype and privacy boundaries in the UI and documentation
- [x] GitHub Pages deployment workflow

## v0.2 — validation and product safety

- [ ] Usability sessions with individuals using fictional data
- [ ] Interviews with estate-planning and digital-legacy professionals
- [ ] Research and cite official provider procedures
- [ ] Threat model and independent review of proposed data flows
- [ ] Versioned import/export schema and migration tests

## v0.3 — secure personal product research

- [ ] Choose architecture and hosting model
- [ ] Design user-controlled encryption and recovery
- [ ] Implement authentication and secure data lifecycle
- [ ] Add revocable, record-level sharing
- [ ] Conduct security and privacy review before accepting real records

## Later — professional pilot

- [ ] Tenant-isolated professional workspace
- [ ] Explicit client consent and revocation
- [ ] Roles, audit events, and case checklists
- [ ] Retention and deletion controls

## Out of scope

- Identity or account ownership transfer from one person to another
- Automated username claims or releases on third-party platforms
- Claiming that inactivity proves death or incapacity
- Storing third-party passwords or accessing private platform messages
